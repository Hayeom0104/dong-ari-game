## 먼저 확인할 점
- GitHub `main`은 2026-10-06 기준 구버전 Unity 소스입니다. 이 브랜치에도 v0.5의 최신 편집 가능 소스는 아직 없습니다.

- v0.5의 변경 사항을 코드를 추측해서 덮어쓰기 전에 **해당 빌드를 만든 Source ZIP이나 원본 Git 작업 디렉터리**를 확보해야 합니다.
- 배포본에 동봉된 PlayMode 27/27 및 Windows 점검 통과는 동봉된 자체 QA 결과입니다. 이 브랜치에서 실행한 테스트로 표시하지 마세요.
