# 동아리 던전

학교 동아리 프로젝트용 Godot 4 기반 액션 로그라이크 프로토타입입니다.

## 현재 구현

- 전사·궁수·마법사 중 고유 캐릭터 선택
- 제한 시간 10분, 총 10개 방 진행
- 기본 공격 자동 진행 및 마나 스킬
- 마나 초당 1 회복
- 방 클리어 후 2개 중 1개 아티팩트 선택
- 빨강: 공격력·치명타
- 파랑: 공격속도·이동속도·회피
- 흰색: 순수 공격력·최대 체력
- 10번째 방 보스와 승리/패배 결과

## 실행 방법

1. Godot 4.x에서 이 폴더의 `project.godot`을 엽니다.
2. 프로젝트 실행 버튼 또는 `F6`을 누릅니다.
3. 캐릭터를 선택하면 게임이 시작됩니다.

현재 버전은 외부 이미지 없이 UI와 핵심 게임 루프를 검증하기 위한 기반 코드입니다.
