# Dong Ari Game

학교 제출용 2D 액션 로그라이트 Unity 프로젝트입니다. 제한 시간 없이 10개의 방을 돌파하는 것을 목표로 합니다.

## 현재 구현

- 전사/궁수/마법사 캐릭터 선택 화면과 고유 능력치
- 이동, 기본 공격(Space)과 고유 스킬(Q), 체력·피격·회피
- 초당 1 마나 자동 회복 및 마나 소비
- 빨강/파랑/흰색 속성 강화 계산
- 방 클리어 후 빨강/파랑/흰색 아티팩트 선택
- 4·9번 방은 전투 없는 상점: 체력 물약 40골드, 마나 물약 50골드, 구매 없이 통과 가능
- 전투 방 완료 시 40 + 방 번호 × 10골드 지급 (아티팩트 선택 후 지급, 임시 밸런스)
- 일반 몬스터·엘리트 몬스터·10번 방 최종 보스
- 후반 방으로 갈수록 1~2개 웨이브가 이어지는 생존 전투
- 플레이어가 전투 화면 밖으로 나가지 않도록 이동 범위 제한
- 시간제한 없는 10개 방과 최종 보스, 승리·패배
- 체력·마나·방·경과 시간을 보여주는 HUD
- Unity에서 첫 실행 시 샘플 `Main` 씬 자동 생성
- 핵심 규칙 EditMode 테스트

## 실행

1. Unity Hub에서 이 폴더를 Unity 6 프로젝트로 엽니다.
2. 스크립트 컴파일이 끝날 때까지 기다립니다.
3. `Assets/Scenes/Main.unity`가 자동 생성되면 열고 Play를 누릅니다.
4. WASD/방향키로 이동하고 Space로 기본 공격, Q로 마나 20을 사용하는 고유 스킬을 사용합니다.

캐릭터를 선택하면 8프레임 픽셀 이동 모션을 적용합니다. 배경과 UI는 프로토타입입니다. 기존 Main 씬을 삭제하거나 다시 만들 필요는 없습니다.

## 색깔과 아티팩트

전투 방 보상으로 색깔별 무작위 1종씩 총 3개를 제시하며 하나를 선택합니다.
각 아티팩트는 색깔 강화 1개와 아래 고유 효과를 모두 부여합니다. 중복 획득은 누적되며 새 도전에서 초기화됩니다.

- 빨강 1개: 데미지 +8%, 치명타 확률 +2.5%p
- 파랑 1개: 공격속도 +6%, 이동속도 +4%, 회피 확률 +2%p
- 흰색 1개: 고정 공격력 +2, 최대 체력 +8

| 색깔 | 아티팩트 | 추가 고유 효과 |
|---|---|---|
| 빨강 | 불씨의 핵 | 데미지 +8% |
| 빨강 | 루비 렌즈 | 치명타 확률 +5%p |
| 빨강 | 진홍 깃발 | 데미지 +4%, 치명타 확률 +2.5%p |
| 파랑 | 푸른 태엽 | 공격속도 +12% |
| 파랑 | 바람 장화 | 이동속도 +8% |
| 파랑 | 안개 망토 | 회피 확률 +4%p |
| 흰색 | 백색 숫돌 | 고정 공격력 +4 |
| 흰색 | 대리석 심장 | 최대 체력 +20 |
| 흰색 | 상아 인장 | 고정 공격력 +2, 최대 체력 +10 |

같은 종류의 백분율 보너스는 합산합니다. 최종 공격력은 `기본 공격력 × (1 + 데미지 보너스 합) + 고정 공격력 합`입니다.
치명타는 75%, 회피는 60%가 상한입니다. 체력 증가 시 기존 방 보상 회복(최대 체력의 18%) 규칙을 따릅니다.
전투 HUD에 색깔 개수가 표시되며, 전투/상점에서 I키로 보유 아티팩트와 최종 능력치를 확인합니다. 목록을 열어도 전투는 계속됩니다.

검증: 색깔별 목록, 중복 누적, 혼합 색깔 계산 순서, 확률 상한과 초기화 EditMode 테스트 추가.
Unity Editor가 없는 작업 환경에서는 실행 테스트와 실제 화면 검증을 수행하지 못했습니다.


## 이동 애니메이션과 몬스터

- 전사/궁수/마법사 각각 8프레임. 이동 시 10fps 반복, 정지 시 첫 프레임, 왼쪽 이동 시 반전.
- 원본 투명 PNG는 `Assets/Resources/Art`에 보존합니다. 비균일한 시트는 `HeroesFrames.json`, `MonstersFrames.json`의 실제 프레임 좌표로 읽습니다.
- 슬라임/고블린/골렘 3종의 원본 모션을 사용하며, 후반 변종 3종은 색상·능력치·이동 패턴을 변경합니다. 별도 신규 그림 6종은 아닙니다.

| 몬스터 | 첫 등장 방 | 특징 |
|---|---:|---|
| 물방울 슬라임 | 1 | 낮은 체력, 멈춤과 이동을 반복 |
| 고블린 정찰병 | 1 | 빠른 추격, 짧은 공격 간격 |
| 이끼 골렘 | 2 | 높은 체력, 느린 이동과 강한 공격 |
| 늪지 슬라임 | 3 | 녹색 변종, 강화된 접촉 공격 |
| 고블린 돌격병 | 5 | 예고 후 방향을 고정해 돌진 |
| 수정 골렘 | 7 | 청색 변종, 높은 체력과 돌진 |

4·9번 방에는 여전히 몬스터가 없습니다. 10번 방의 고대 수정 수호자는 골렘 모션을 크게 표시하며 돌진합니다.
정예는 일반 몬스터의 강화 형태로 마지막 웨이브에 등장합니다. 확대된 적도 공격할 수 있도록 공격 거리를 몸 크기에 맞췄습니다.

확인할 항목: 각 직업의 이동/정지/좌우 반전, 돌진 전 밝아지는 예고, 4·9번 방 상점, 10번 방 승리, 재시작 후 직업 변경.
실제 Unity 컴파일·Play Mode·인게임 캡처는 아직 실행하지 않았습니다. 문법/프레임 좌표 검사는 Unity 실행 검증을 대체하지 않습니다.
