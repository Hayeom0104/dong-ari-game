# Dong Ari Game

학교 제출용 2D 액션 로그라이트 Unity 프로젝트입니다. 제한 시간 없이 10개의 방을 돌파하는 것을 목표로 합니다.

## 현재 구현

- 전사/궁수/마법사 캐릭터 선택 화면과 고유 능력치
- 이동, 기본 공격(Space)과 고유 스킬(Q), 체력·피격·회피
- 초당 1 마나 자동 회복 및 마나 소비
- 빨강/파랑/흰색 속성 강화 계산
- 방 클리어 후 빨강/파랑/흰색 아티팩트 선택
- 4·9번 방은 전투 없는 상점: 체력 물약 40골드, 마나 물약 50골드, 구매 없이 통과 가능
- 전투 방 완료 시 40 + 방 번호 × 10골드 지급 (아티팩트 선택 후 지급, 임시 밸런스)
- 일반 몬스터·엘리트 몬스터·10번 방 최종 보스
- 후반 방으로 갈수록 1~2개 웨이브가 이어지는 생존 전투
- 플레이어가 전투 화면 밖으로 나가지 않도록 이동 범위 제한
- 시간제한 없는 10개 방과 최종 보스, 승리·패배
- 체력·마나·방·경과 시간을 보여주는 HUD
- Unity에서 첫 실행 시 샘플 `Main` 씬 자동 생성
- 핵심 규칙 EditMode 테스트

## 실행

1. Unity Hub에서 이 폴더를 Unity 6 프로젝트로 엽니다.
2. 스크립트 컴파일이 끝날 때까지 기다립니다.
3. `Assets/Scenes/Main.unity`가 자동 생성되면 열고 Play를 누릅니다.
4. WASD/방향키로 이동하고 Space로 기본 공격, Q로 마나 20을 사용하는 고유 스킬을 사용합니다.

샘플 씬은 임시 도형만 사용합니다. 실제 캐릭터, 적, 방 배치와 UI는 다음 구현 단계에서 교체합니다.
